batched sim perf summary
branch: perf/batched-sim-benchmark
optimized source commit: 36d509b
baseline source commit: a06fe5e
date: 2026-04-26

Benchmark tool:
- build: make build-bench-sim
- run: make bench-sim ARGS="--batch 1024 --frames 4000 --warmup 400 --mode rollout"
- modes:
  - rollout: timed msl_batch_step_input only, then one untimed final msl_batch_write_compare for checksum
  - rollout_compare: timed msl_batch_step_input plus msl_batch_write_compare each frame
- input source: deterministic precomputed random input ring, so timed loops do not generate random
  numbers.

Environment note:
- The machine had unrelated CPU-heavy work running during review cleanup, including Dolphin.
- Treat exact timings as noisy. The clearest current comparison is the pinned, interleaved
  old/new rollout sweep in reports/bench/batched_sim_adjacent_pinned.txt.

Implemented wins:
- Added a native C benchmark binary under tools/bench.
- Narrowed singles hot loops in input, shield, hitbox, and hurtbox refreshes to active players
  instead of clearing/processing all 4 player slots every frame.
- Reduced dynamic collision matrix scratch work by carrying only the current parent scale along the
  root-to-part chain.
- Skipped dynamic collision table lookup work when no dynamic collision override is active.

Review cleanup:
- Regenerated reports with branch/source metadata.
- Added a nonzero final-state checksum for rollout mode as well as rollout_compare.
- Added a 4-player regression guard to ensure active-player refresh loops still process slot 3.
