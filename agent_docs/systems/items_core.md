# Items Core Source Completion

Scope: item lifecycle for supported RL 1.0 gameplay: item creation/destruction, update order,
ownership, public item state, item hitlists, item timers, and lifecycle RNG. Projectile-specific
behavior and reflect/shield-bounce live in [projectiles_reflect.md](projectiles_reflect.md).

Supported item families in this closure are the generic item substrate used by Fox/Falco blaster
shots, Fox/Falco side-special illusion/phantasm articles, Yoshi's Story Shy Guys, Dream Land Whispy
wind, and shared item hitlist/damage handoff boundaries. Full arbitrary Melee item GObj behavior is
outside RL 1.0 unless it feeds those supported gameplay paths.

Status vocabulary: **OPEN**, **INVENTORY NEEDED**, **CLOSED**, **RETAINED SOURCE-POLICY**, and
exceptional **BLOCKED** only.

## Validation Evidence

  Whispy wind, item hitlists, and shared item damage/reflected-damage handoffs.

  scope wording, stage-item data contracts, and seed/reseed hidden item lane coverage.

  and projectile/item source ownership; projectiles-specific closure is tracked separately in
