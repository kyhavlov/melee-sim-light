# Projectiles / Reflect Source Completion

Scope: Fox/Falco laser projectile lifecycle for supported RL 1.0 gameplay: blaster article spawn
pulses, laser projectile slot/update order, laser HitCapsule geometry, item-vs-fighter
BODY/SHIELD contact, reflector and powershield transfer, shield bounce, item hitlists/victim
lifetime, projectile consume/despawn, zero-KB/Falco-KB damage behavior, source identity, and
seed/reseed reconstruction. Generic item lifecycle remains in [items_core.md](items_core.md) unless
it is consumed by the supported laser/reflect path.

Out of scope for this doc: item-only collision for non-laser items, non-Fox/Falco projectile
families, cosmetic laser/blaster rendering beyond serialized gameplay/debug state, and generic item
proc priority closure that does not affect supported laser contacts.

Status vocabulary: **OPEN**, **INVENTORY NEEDED**, **CLOSED**, **RETAINED SOURCE-POLICY**, and
exceptional **BLOCKED** only. This document has no BLOCKED rows.

## Evidence Summary

- Data contracts: `MSLLASR1` v6 (`data/items/lasers.bin`), `MSLITAR1`
  (`data/items/articles/fox_falco.bin`), `MSLFTSC1` move-table projectile pulses, and item common
  shield-bounce thresholds.
- Runtime source refs are local to the code in `src/items.c`, `src/item_reflect.h`,
  `src/laser_params.h`, and `src/combat.c`.
- Projectiles / Reflect is **CLOSED** for supported RL 1.0 Fox/Falco laser gameplay. Remaining
  generic item lifecycle closure belongs to `items_core.md`.
