# Agent Docs

This directory holds long-lived project notes for agents and humans working on
`melee-sim-light`. Keep top-level files current; put historical snapshots under
`archive/`.

## Active References

- `SPEC.md` - gameplay and simulator behavior specification.
- `DATA_CONTRACT.md` - extracted data formats consumed by the C core.
- `DEVELOPMENT_WORKFLOWS.md` - common build, validation, and debug commands.
- `SSANIM_AXIS_BASIS.md` - animation basis and pose-axis notes.
- `AGENT_META_NOTES.md` - process guidance, not gameplay authority.
- `LONG_WORK_PROMPT.md` - reusable long-work prompt text.
- `dolphin_tooling/` - Dolphin engine-dump and local source reference notes.

## Archived Context

The old roadmap and bring-up notes were removed. Prefer current validation
reports, source comments, and `SPEC.md` over historical snapshots.
