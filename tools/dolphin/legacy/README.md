# Legacy Dolphin Probes

These scripts were retained for historical reference and are not part of the active workflow:

- `playback_step_probe.py`
- `engine_dump_capture.py`
- `dolphin_probe_ecb.py`
- `dolphin_mem_probe_ecb.py`

They rely on local/legacy dependencies (`libmelee`, `dolphin_memory_engine`, `enet`, `peppi_bytes`)
and are intentionally excluded from the current, playback-only forensic path.
